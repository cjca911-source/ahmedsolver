# AhmedSolver

AhmedSolver is a focused bilingual engineering website with two core tools:

- Mohr's Circle Solver with responsive SVG drawing
- Beam Deflection Solver with beam case selection and shape-based moment of inertia support

The site is static and GitHub Pages friendly. For local preview, run the small Express server with:

```bash
npm start
```

Then open `http://localhost:3000/`.
